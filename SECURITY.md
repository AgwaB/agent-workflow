# Security Policy

## Reporting a vulnerability

Report suspected security vulnerabilities in agent-workflow [privately through GitHub](https://github.com/AgwaB/agent-workflow/security/advisories/new). Do not disclose vulnerability details in public issues or pull requests.

Please include, when available:

- A description of the vulnerability and its impact.
- Minimal reproduction steps or a proof of concept, with a sanitized workflow or configuration if relevant.
- The affected agent-workflow version or commit, the host (CLI, Claude Code, Codex, Claude desktop app, Pi) and executor CLI versions, the Node.js version, and the operating system.
- Any known mitigations.

Do not include credentials, access tokens, or unrelated private data, even in a private report. We can discuss the report and coordinate a fix and disclosure through GitHub's private advisory thread.

For ordinary bugs and change proposals, use the public issue forms described in [CONTRIBUTING.md](CONTRIBUTING.md).
